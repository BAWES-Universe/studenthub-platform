## Summary — highest-value frontend-only findings (10 lines)

1. **Anonymous AWS credential leak**: `GET /aws/config` is fetched before login without a bearer (`aws.service.ts:70-95`) and the backend removed its authenticator (`AwsController.php:15`); uploads are `public-read` with client-chosen keys. Widen SHU-134/OP-05 to "unauthenticated".
2. **Clock-in location is mandatory only in the UI** (`track-work.page.ts:129-221`): denial blocks the request with an alert, no retry/queue; the server accepts null coordinates and overwrites start with stop (WK-F1). D-WK1 must be decided server-side; client offline/skew behaviour = none, server timestamps.
3. **Manual hour entry is client-validated only**: end>start, date ≤ today, note required exist only in `custom.validator.ts`; backend `actionAddHour` stores `strtotime("hh:mm a")` on *today's* date regardless of `date` and can write negative `total_time` (`CandidateWorkingHourController.php:183-197`).
4. **Write requests are auto-retried 3× on 5xx/timeouts** (`genericRetryStrategy.ts`, `authhttp.service.ts:71`) against endpoints with no idempotency or duplicate guards (apply RC-F2, manual log, tickets, chat).
5. **Two-step auth is unimplemented on mobile**: `token_status` ignored (`auth.service.ts:444-468`); a candidate with `enable_two_step_auth` gets an inactive token and is logged out on the first call — confirms ID-04 replacement by Authentik must cover this client first.
6. **reCAPTCHA is decorative**: executed on register/reset/verify but every server-side `verify` is commented out (`AuthController.php:20-29, 107-116, 201-210`).
7. **`internal_note` reaches the candidate**: mobile only renders `interview_note`, but `RequestInterview` has no `fields()` filter, so `GET /requests/interview-requests` ships `internal_note` (RC-F6 resolved: hidden client-side only).
8. **Push audience is tag-based and client-owned**: OneSignal tags `candidate_id/name/email` set in `app.component.ts:514-518`; no player/device id ever reaches the backend (CM-F9 confirmed). Web build also injects the OneSignal CDN SDK.
9. **No appeal UI** (WK-11), no job board (`/jobs`), no two-step/session management, interview-view is an empty stub, Jobs/Payments desktop tabs commented out; the profile-complete gate and the "Track" tab are driven by a cached local profile, not by server authz.
10. **Hygiene**: release keystore + password, Play service-account JSON, `google-services.json`, `private_key.pepk` committed; 1 s unread-count polling; dead MOCI civil-ID scraper with hard-coded VIEWSTATE in the bundle; Mixpanel/Hotjar/GTM PII without consent.
